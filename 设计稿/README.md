# 设计稿文件夹 —— 怎么让 GPT 出想法、Codex 写代码

这个文件夹是给"策划"用的。你可以在 GPT / ChatGPT 那边尽情想机制、编名字、
算数值、写描述；把结果按 `_模板.md` 的格式丢进这里，再让 Codex 读文件实现。

## 三步流程

1. **让 GPT 按 `_模板.md` 填一份设计稿**
   - 一套装备 / 一把武器 / 一个套装，各写一个文件。
   - 文件名建议：`武器_英文id.md`、`护甲_英文id.md`、`套装_xxx.md`。
   - 不确定英文 id 就让 GPT 起一个，Codex 会按包里现有命名习惯再统一。

2. **把文件放进这个文件夹**
   - 路径就是 `D:\数据包\设计稿\`。
   - 也可以直接把 GPT 的输出贴进聊天，但放文件更稳，长文本不会被漏看。

3. **对 Codex 说**
   - "读设计稿/武器_xxx.md，按这个做。先做效果，give 最后一起做。"
   - 或者："读设计稿/护甲_xxx.md，参考余烬/焚舟的写法。"

## 分工边界

- **GPT 负责**：机制、数值、名字、lore 文案、套装联动、边界情况。
- **Codex 负责**：1.21.5 的 mcfunction 语法、真实 ID 核对、宏函数、文件结构、
  自检、部署到测试世界、踩坑修正。

## ⚠️ 重要

**不要让 GPT 直接写最终 mcfunction 代码。** 它可以写伪代码帮助表达，
但粒子 ID、音效 ID、附魔 ID、伤害类型 ID、选择器范围语法这些东西它经常编，
1.21.5 尤其容易翻车。Codex 会以"机制描述"为准重新实现，不会盲抄它给的代码。

## 写设计稿时最好带上这些

- 这是"最大魔力值口径"还是"当前魔力值口径"？会不会吃「下一次技能加成」？
- 这个效果会不会消耗通用标签（渊海 / 流火 / 夜火 / 噬心 / 白昼梦）？
- 会不会造成伤害？伤害是玩家来源还是无来源？会不会被受伤无敌帧吃掉？
- 多人同时用会不会互相顶掉？同一只生物重复受到效果会怎样？
- 目标死了、没打中、目标在 9 格外、玩家中途脱装备，这些边界怎么处理？
