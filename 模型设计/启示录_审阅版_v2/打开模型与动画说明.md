# 启示录 v2 · 疾翻灾示（未实装）

## 打开与播放

1. 在 Blockbench 5.x 用「文件 → 打开模型」打开 `启示录_v2_分组动画.bbmodel`。这是通用模型（Generic Model），不要导入到已有 Java 方块/物品模型项目。
2. 切换「动画 / Animate」，左侧动画列表选择 `02_施法_疾翻灾示与三阶强化`，从 0 秒播放。一次只播放一段。
3. 如果使用旧版，打开 `启示录_v2_旧版兼容.bbmodel`。它使用 4.10 文件结构，动画和材质均已内嵌。
4. 另附 `启示录_v2.animation.json` 作为独立动画备份。在支持此导入格式的动画编辑器中加载到本通用模型即可；它不是可以直接放入 Java 资源包运行的物品文件。

上一版源文件确实包含两段动画。空列表的具体原因尚未复现，不能断定是版本问题；如果仍为空，请提供 Blockbench 版本及打开方式。当前已完成源文件、关键帧和实际几何渲染校验，尚未完成 Blockbench GUI 导入验证。

## 新动作

- 待机：每 5 秒短促连翻 3 页，其余时间静置。
- 施法：0.5 秒移入中心，连续翻 16 页，最后一页放缓，约 2.21 秒停稳；停页沿用原来的星图与日蚀画面，不新增「灾示」文字或改版页纹。4 秒、8 秒各连翻 10 页，均在灾示触发前停稳。
- 3 / 6 秒：普通金色短芒与纸面符文闪亮。
- 9 秒：演示三页全部消耗时的强化终章。双层断续法环反向展开、光柱上涌、悬浮灾谕星出现、书本短促后坐后回稳。
- 11 秒后回到原位置。动画中的居中位移是设计预览，游戏第一人称位置还需实装时校准。
