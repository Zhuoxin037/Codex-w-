# 圣骸遗骸 · 骨冢与多标签形体审阅

这是实际通过 Blockbench MCP 制作、保存与导出的模型。当前处于形体审阅阶段，尚未加入游戏，也尚未制作动画。

- `圣骸遗骸_分组模型.bbmodel`：241 个方块、22 个分组、3 张内嵌贴图，可直接打开编辑。
- `圣骸遗骸_模型与多标签预览.png`：模型正背面，以及无标签、流火＋噬心＋渊海、五标签三种状态。
- `审阅资源/assets/sacredrelic/models/entity/remnant.json`：完整 Java 模型，配套纹理位于同一审阅资源目录的 assets 内。可调整整体显示，不要只调整某一张记忆牌。
- `阶段验收.json`：检查全部 32 种标签组合。236 个基础方块，每个标签增加 1 个刻印薄层；五种标签同时显示为 241 个。

五枚牌从遗骸自身左至右依次为流火、夜火、噬心、白昼梦、渊海；从正面观看时左右相反。刻印各有独立分组与固定位置，多个标签同时点亮，魂火本体始终保留圣骸的淡青白主色。当前编辑工程默认五个刻印均显示，便于逐个调整；预览中按组合独立隐藏。

颅骨的 39 个方块共同绕同一枢轴倾斜 22.5°，属于同一完整头骨姿态。其他骨骼、铜弧、布料均用轴向阶梯结构。肋骨与眼窝保留实际空腔，魂火、祭布、骨堆、纪念弧和标签可分别编辑。

MCP 模型检查 0 问题；已检查 Java 导出范围、旋转角度、面数量、纹理引用及 UV。预览由实际保存的模型渲染，无额外辉光后期。128 像素刻印图使用 256 单位 UV，离线渲染已按同样比例转换，避免刻印混位。

下一阶段在形体确认后制作魂火明灭、生成与共鸣表现，再接入原有遗骸死亡位置、240 刻寿命、标签快照与技能结算。
