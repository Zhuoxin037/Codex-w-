# 风帆 · 概念待审阅

本阶段仅设计外观，不改资源包、数据包和现有技能。概念图不是实际模型渲染。

## 外观方向

一柄以桅杆、鼓帆与导航罗盘组成的引风法杖。深灰青木质桅杆、灰白主帆、暗青后帆、少量旧铜结构。主帆以分段曲面表现鼓起的体积，后帆错开到背侧，避免正侧面都像薄纸。握柄保留清晰握持区域。

罗盘下方四个分离的记录槽：渊海深蓝、流火红色、白昼梦粉色、噬心近黑色。配色与当前 sail/whirl_dot 的技能颜色一致。记录槽用于提示记录状态，不改变原有技能规则。

## 动效设计意图（待实际模型验证）

- 待机：帆片轻微起伏，风向针缓慢偏转，少量短风痕。
- 普攻记录：根据记录结果点亮对应槽位，可同时显示多种被记录属性。
- 技能：帆面迎风，罗盘短暂加速；三秒吸附脉冲与现有旋风事件对齐。
- 召回：短风痕向握持者收拢，移动的是已有旋风，不移动被记录生物。

这些是表现方案，不新增持续范围、伤害或耗魔。具体几何动画方式待分阶段建模时在 Java 1.21.5 中验证。
