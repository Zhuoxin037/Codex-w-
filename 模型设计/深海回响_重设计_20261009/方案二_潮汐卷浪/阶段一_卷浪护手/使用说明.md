# 深海回响 · 卷浪护手阶段

已完成第一阶段实际模型：不对称开放卷浪、深蓝立体潮核、窄镶座、固定扣眼、五个交错短链环和水滴晶坠。673 个立方体，14 个分组，一张内嵌贴图。每个立方体均有唯一分组归属，UV 和 Java 静态导出范围检查通过。

原生工程：`深海回响_卷浪护手_分组.bbmodel`。整体审阅 JSON：`显示调整示例/assets/deepseaecho/models/item/deepseaecho.json`，含几何和 display，沿用当前 `deepseaecho/models/item/sword.json` 的握姿。尚未替换原游戏资源。

护手两侧是连续的蓝钢骨架、凹面和分层银浪脊；潮核具有真实前后厚度。扣爪插入护手，锁链从固定扣眼连接至晶坠，链环交替朝向。

剑刃、剑柄、单侧浪刃和流浪动画属于下一阶段，需先确认本阶段的轮廓与核心比例。本阶段未添加动画。
