# 启示录 · 三页灾谕（审阅版）

这是可编辑的 Blockbench 通用模型源文件，包含实体翻页的骨骼关键帧；尚未部署到游戏。
用 Blockbench 5.x「文件 → 打开模型」打开 `启示录_分组动画.bbmodel`。贴图已内嵌，也另存到“贴图”文件夹方便修改。

## 怎样调整

- `00_整体握姿与施法位移`：整本书。动画中的位置关键帧是居中动作设计；实际第一人称握姿还须进游戏校准。
- `01_左侧书体`、`02_右侧书体`：左右书封、页块、页顶分别成组。每个金属包角也独立成组。
- `03_书脊_铰链与预言之眼`：书脊与远端琥珀。
- `04_三枚启示书签_各自可调`：三条书签的转轴在书口连接处，可分别移动或旋转。
- `05_活动书页_绕书脊真实翻动`：三张活动页，各含主翻页轴和六段柔性纸片；不要只移动单张纸片而遗漏它的转轴。
- `06_施法光效_可整组隐藏`：符文点亮层及短光芒。在编辑模式下可点眼睛隐藏本组和活动页，查看日常静态书体。

在「动画」模式分别选择 `01_待机_每5秒翻一页` 和 `02_施法_居中翻页与三次灾示`，一次只播放一个动画。
待机 5 秒循环，3.75 秒开始翻页；施法预览含入场、快速翻页、4/8 秒换页以及 3/6/9 秒灾示闪光，11 秒后归位。
三枚书签对应三页启示；此次先交付形态与动作预览，记页点亮/消耗熄灭的游戏计分板联动等你确认后再接。

## 实装边界

原版 Java 资源包不会直接播放 bbmodel 骨骼动画。这份通用模型是可编辑的动画母版；确认后会把运动部件烘焙为原版支持的状态模型，并用现有技能计时驱动。
当前不提供可直接替换运行的游戏 JSON，避免把通用动画源文件误当成 Java 物品模型。不要直接用“转换格式”覆盖此母版。
预览只模拟物品自身发光符文和短光芒；不承诺原版能照亮周围环境，也没有依赖光影包的泛光后期。
