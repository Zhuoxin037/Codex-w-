# 启示录整体显示调整

在 Blockbench 中打开 `D:\数据包\sweetdream_rp\assets\sweetdream\models\item\apocalypse.json`，进入「显示」调整整体握姿，保存到原路径。

然后双击此文件夹的「同步启示录显示.bat」，它会更新待机握姿及移动衔接，并部署到测试存档。进入游戏按 F3+T 重载资源包。

2026-10-09 居中修复：快速翻页、灾示及维持施法时固定使用原来的居中姿态；你的整体握姿调整只影响待机。移入中心和收回时逐帧衔接新握姿，重复同步不会把待机偏移叠加到居中施法上。第一、第三人称均使用此规则；GUI、地面、展示框等仍整体同步。

整体 JSON 显示平放的整本书，便于定位；实际游戏仍是原来的展开书本和全部动画。位置、旋转均可修改；缩放时请保持 X、Y、Z 三个数值相同。原生分组及动画仍使用 `模型设计\启示录_审阅版_v2\启示录_可编辑动画母版.bbmodel`。

`显示基准.json` 保存各部件原始姿态，供同步使用，请勿删除。同步始终从基准计算，重复点击不会叠加位移。

2026-10-09 编码修复：两份新增 PowerShell 脚本已补上 UTF-8 BOM。旧文件无编码标记，Windows PowerShell 5.1 会把中文误读，报“字符串缺少终止符”，使同步和普通部署一起中止。现已按批处理使用的同一 PowerShell 版本验证。你修改过的主 JSON 保持不变。
