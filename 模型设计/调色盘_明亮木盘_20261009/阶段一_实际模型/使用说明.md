# 明亮木盘调色盘 · 实际模型审阅

本阶段按已确认概念制作薄枫木盘、贯穿拇指孔、三个浅木槽、厚涂颜料以及倾盘动作草案。尚未替换游戏内模型。

原生工程为「调色盘_明亮木盘_分组动画.bbmodel」，使用支持动画的 free 格式，有 22 个实际分组、2 段原生关键帧动画。三个槽各有红、黄、蓝备选组；同一槽只显示一种颜色。默认展示三色，第三槽仍是超限预留示意。游戏现有双槽积攒规则尚未改动。

整体显示 JSON：`显示调整示例/assets/palette/models/item/palette.json`。它包含整个模型的几何和 display，可以直接在 Blockbench 的 Java 模型显示模式中调整整体握姿；已复制用户当前游戏主 JSON 的 display。原生 free 工程用于分组和动画编辑，显示入口另用上述 JSON。

默认三色可见 704 个立方体；母版 964 个，其中包含隐藏颜色备选。两张内嵌贴图，动画关键帧 UUID 均独立。厚涂起伏、拇指孔不封堵、分组归属、UV 和 Java 静态元素范围检查通过。

MCP 恢复后曾报告 Blockbench 5.2.2，但打开工程时连续超时，未完成软件内打开验证；当前图片和 GIF 均由交付 .bbmodel 的真实几何、贴图及关键帧渲染。已核对本机 Blockbench 源码，free 支持骨骼和动画模式，5.0 工程读取独立 groups 与 outliner。

倾盘汇色 GIF 是动作草案：盘体倾斜、颜料轻微抬起和拉伸，再收回。具体技能色带及游戏逐帧接入将在外观确认后完成。已批准的颜料球和现有运行函数没有改写。
