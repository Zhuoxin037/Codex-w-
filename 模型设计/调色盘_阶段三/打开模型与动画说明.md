# 调色盘 · 第三阶段：提色、汇聚与飞出

保持第二阶段的盘形、三槽、希腊回纹、青铜包边与橄榄枝。两段可编辑骨骼关键帧已烘焙为游戏动画，按用户修改的握姿接入；部署结果以 `.workbuddy/palette_runtime_deployment.json` 为准。

## 打开动画

在 Blockbench「文件 → 打开模型」打开 `调色盘_分组动画.bbmodel`，进入「动画」模式。在动画列表选择下面一段并播放，勿同时选中两段动画。

- `01_待机_轻柔持盘`：4 秒循环，盘面只有很小的持握起伏，颜料留在槽内，施法部件隐藏。
- `02_施法_提色汇聚与飞出`：1.6 秒单次。先前倾起手，颜料从对应槽提起并收小，独立色带向盘面中心上方汇聚，组成一枚色彩向前飞出，最后恢复原位并留下空槽。

母版默认展示「I 黄、II 蓝、III 空」便于立即播放。空盘素白、双红和第三槽三色也已经由同一组动画检查和渲染。没有把普通两槽容量改成三槽。

`调色盘_施法动画.gif` 与 `调色盘_施法动作分镜.png` 使用该文件的真实几何、内嵌贴图、分组可见性和关键帧渲染。没有用概念插画或外加光晕代替模型动画。

## 分组编辑

盘体、孔壁、每个槽、边扣、回纹、枝叶延续前一阶段的独立分组。总根组以拇指孔附近作为动作轴心。

各槽的颜料填充容器都有独立提起和缩小的关键帧。`07_施法_色带与汇聚` 中包含每槽七段色带、单枚色彩汇聚/飞出组、素白笔触和小亮屑。色带各段有独立关键帧，红/黄/蓝为互斥颜色备选；每种颜色都能用于任意一个槽，包括重复颜色。调整色带运动应选择色带的「段」组，调整发射方向应选择 `08_色彩_单枚汇聚与飞出`。

颜色备选在导出时按当前槽位选择。此母版的默认黄蓝状态只是动作审阅示例；普通技能不会同时绘制所有隐藏备选。

只改静态外形时可以暂时关闭施法组的显示；播放施法前应重新开启，并在动画模式使用关键帧查看，不要把编辑模式的色带装配位置当成动画最终位置。

## 总体显示位置 JSON

正式入口改为工作区 `sweetdream_rp/assets/palette/models/item/palette.json`，游戏目录也有同路径副本。这是包含完整空盘几何和四张贴图引用的 Java 模型，可在 Blockbench 的「显示」模式调整整体握姿，导出覆盖同一文件。`显示调整示例` 保留本次用户已修改的输入设置。

所有帧、槽位颜色与施法部件已共享这个总模型的显示设置，避免只改主体时动画部件错位。

本次握姿已同步到 bbmodel；之后 JSON 与 bbmodel 并非实时同步。编辑造型或动画应使用 bbmodel；编辑游戏总体握姿应使用正式总 JSON，并同步到游戏资源包后 F3+T。

## 数量与检查

母版共 818 个立方体，含所有隐藏颜色备选和施法备件；158 个分组、4 张内嵌贴图、2 段动画。空盘待机 628 个，双色待机 648 个，双色施法峰值约 675 个；第三槽示例峰值约 693 个。这些是源动画中实际参与绘制的元素数量，不是已在游戏实测的帧率。

检查元素/分组 UUID 与引用唯一性、六面记录、UV、动画骨骼引用、关键帧时间、Java 静态坐标和旋转限制。还检查了双色、双红和三色动作结束时，几何全部恢复到原始空盘，色带和颜料不残留。

尚未进行 Blockbench GUI 或游戏测试；游戏技能耗魔、伤害、追踪、冷却、双色上限与清空时机均未修改。实际“色彩”仍由现有逻辑生成一枚，现已替换为带实体拉丝尾巴、末端液滴和轻微挤压动效的粘稠颜料团，另有彩色粒子拖尾和偶发亮粒。完整路径和实装说明见工作区 `调色盘_模型说明.md`。
