# 风帆 · 阶段一审阅

已完成桅杆、皮革握柄与尾锥、镂空罗盘及独立指针、四个属性记录槽、连接环与垂饰。180 个立方体，24 个分组，1 张内嵌贴图。

当前尚未制作主帆、后帆、帆骨与动作；这些分组是下一阶段的预留结构，不是丢失的模型。未修改游戏资源包或技能。

## 打开与编辑

用 Blockbench「文件 → 打开模型」打开 `风帆_阶段一_分组.bbmodel`。这是通用模型母版，包含总根组和部件子组。贴图内嵌，并另存于“贴图”目录。

罗盘指针以轮毂为独立旋转中心；四象槽可分别选择。主帆预留五个形变带、后帆预留三个形变带。当前动画列表为空，尚未制作动画。

## 整体显示位置 JSON

`显示调整示例/assets/sweetdream/models/item/sail/display.json` 是统一显示设置入口：

- `rotation`：旋转角度。
- `translation`：位置偏移。
- `scale`：三个方向的缩放。
- `firstperson_righthand` / `firstperson_lefthand`：第一人称双手。
- `thirdperson_righthand` / `thirdperson_lefthand`：第三人称双手。
- `gui`、`ground`、`fixed`：物品栏、掉落、展示框。

同目录 `stage1.json` 已通过 parent 引用 display.json，没有自己的 display 覆盖。修改 display.json 即可统一调整这个阶段模型的显示变换。它是 Java 物品模型的父模型文件，不是自定义脚本配置。该目录只是导出结构示例，不是已安装的完整资源包，尚未添加物品绑定。

bbmodel 内也保存了初始 display 设置；直接修改外部 JSON 不会实时改变已经打开的 bbmodel。正式导出将以用户调整过的 display.json 为准。后续动画模型会共用显示设置，实际游戏内握姿还需实装时校准。

## 已确认的施法方向

施法时主帆遇到强风，形成受风鼓起、回落、再鼓起的形变。靠近桅杆的连接处约束更强，自由帆缘摆幅更大；形变沿帆面传播，后帆延迟跟随。不是仅滚动贴图，也不是整张硬帆一起摆。具体分段数量与转轴待第二阶段帆体完成后验证。

本阶段检查了模型结构、分组引用、六面记录、UV 范围、Java 坐标及旋转限制和父模型/贴图引用；预览为源模型的软件渲染。尚未在本机 Blockbench GUI 或游戏中实测。
