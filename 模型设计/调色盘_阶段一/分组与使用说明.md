# 调色盘 · 阶段一审阅

依据用户选回的 `调色盘_古希腊风格_概念图.png` 建造，最终保留该图的蓝色回纹、青铜边扣和立体橄榄枝，不采用装饰精简版。本阶段先确认盘体和三个浅槽，装饰在下一阶段添加。

空盘当前显示 363 个立方体；母版总计 429 个立方体，包含九种默认隐藏的槽位颜料备选。普通双色显示 379 个立方体，三槽全满显示 385 个。26 个分组，3 张内嵌贴图。

## 打开和调整

Blockbench「文件 → 打开模型」打开 `调色盘_阶段一_分组.bbmodel`，这是分组可编辑母版。

- `00_调色盘_整体与握持`：整个物品的根组。
- `01_肾形盘体`：木胎、连续木纹混色面和边缘倒角分别成组。
- `02_贯穿拇指孔`：贯穿孔内壁，盘体几何已经避开孔内，不是贴图画的黑圆。
- `03_三个独立颜料浅槽`：I / II / III 各自分组，槽底、槽壁和颜料填充可分别调整。
- 每槽下有红、黄、蓝三种颜料子组，初始隐藏。在同一个槽内只开启一种颜色；开启多个会在同一位置重叠。
- 回纹、青铜扣、橄榄枝和施法表现的预留分组当前没有元素。

当前动画列表为空，施法动画将在装饰及外观确认后制作。

## 颜色与施法表现方案

普通状态继续读取现有两槽，支持重复颜色；第三槽保持独立显示入口，等待超限规则使用。预览中第三槽填满仅为显示能力示意，不代表已经改动普通技能容量。

施法设计：盘面短暂前倾，持有的颜料从各槽略微提起，拉成短色带，再汇成一枚“色彩”向前飞出；保留各自颜色，避免混成难以辨认的杂色。槽内颜料在发射后回到空槽状态，与当前技能成功后清空颜色的逻辑一致。没有颜色时用素白的短笔触汇出“色彩”。

所有颜料、色带和汇聚点独立分组，能够手动修改位置与动画关键帧。画笔目前仅为概念配件，不附加在盘体上。
