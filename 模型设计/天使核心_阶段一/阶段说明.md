# 天使核心 · 阶段一

本阶段为斧刃与核心的实际 Blockbench 工程，尚未实装。

- 文件：天使核心_阶段一.bbmodel。
- 使用 Blockbench 5.2.1 和 BlockbenchMCP 0.3.1，通过 MCP 创建并细化。
- 477 个立方体，12 个原生分组，贴图内嵌；通用模型格式可进入动画模式。
- 分区：整体、三层翼甲、上/中/下翼甲、刃缘、镂空核心框、暖白晶体、上/下断环、配重、柄座。
- 当前包含宽月牙斧刃、三层金属翼甲、前后八角框、晶体、断环及短配重刃。长柄和动画待确认本阶段后制作。
- MCP 模型检查：无退化立方体、缺失贴图、越界 UV 或重叠平面问题。
- 预览须在 Blockbench 图形上下文正常时拍摄；空白 PNG 不作为有效审核图。
- 审核_正面.png 与审核_斜侧.png 为 MCP 从实时模型几何生成的临时光照渲染，不是 AI 概念图，也不代表游戏内效果。
