2026-10-10。保留用户在 Blockbench 调整的大圆环摆放，品质方向按风行、启示录：原版契合、清楚轮廓与有层次的细节。已同步到 Minecraft 1.21.5 的测试包体存档。

## 当前文件

- `极光与幻梦_分组模型.bbmodel`：通用格式母版，733 块、36 个实际分组、2 条可编辑动画。用「动画」工作区编辑悬晶/圆环关键帧；刃内像素流动使用游戏贴图动画。
- `极光与幻梦_整体显示调整.bbmodel`：游戏兼容的 Java 格式，739 块。在「显示」工作区修改总体握姿并保存。
- `同步极光显示.bat`：把保存的总体 display 同步到全部 66 份游戏模型，然后部署。同步步骤已用 Windows PowerShell 5.1 实际运行，PS1 采用 UTF-8 BOM。
- 整体 JSON：`D:/数据包/sweetdream_rp/assets/sweetdream/models/item/aurora_dream.json`；动画部件在同级 `aurora_dream/`；物品入口在 `assets/sweetdream/items/aurora_dream.json`。

不要只改 body/某个帧的 display；否则其余部件会错位。两个 bbmodel 分别用于动画和显示编辑，不能互相覆盖。同步显示只同步 display；几何/动画编辑需要重新导出。

## 动效和兼容导出

待机：刃内极光 32 帧贴图、3.2 秒循环；圆环与悬晶 24 帧姿态、4.8 秒轻浮循环。施法成功后播放 32 帧、1.6 秒汇光，之后定格；原技能 4/8 秒钟声同步短暂微亮。魔力、冷却、目标范围、时停时长、原粒子和钟声音色未改。

固定剑身 500 块、极光槽 100 块复用，只切换 139 块圆环/悬晶。手持时动画，GUI/掉落物使用整体模型。相关资源约 5 MB。

用户圆环原点 `(0.15,0.2,0.3)`，旋转 `(-62.5,0,0)`。Java 1.21.5 不接受复合元素旋转，游戏将原 114 个环元素改成 120 个合法分段/嵌饰，保持相同世界中心、平面和半径；母版保留原姿态。剑刃 304 块、50 个渐变截面，剑刃不使用旋转立方体，正背面都有贴合凹槽。
