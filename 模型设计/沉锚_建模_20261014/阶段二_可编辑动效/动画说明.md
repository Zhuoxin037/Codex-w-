# 沉锚 · 四向锚爪可编辑动效

2026-10-14。用户以“还不错。”认可四向静态形体，随后要求继续。本阶段从已认可的静态工程制作原生动画。用户之后明确授权“是的话你可以实装给我看看效果了”，现已完成阶段三游戏接入并部署；最新状态和游戏表现差异见 `../阶段三_游戏接入/接入说明.md`。本阶段动画母版保留。

## 打开与编辑

- 最新母版是 `沉锚_四向锚爪_分组可编辑动画.bbmodel`。使用 Blockbench 打开，进入动画工作区，每次单独启用一个动作。
- 通用格式工程包含901个立方体、28个实际分组、3张内嵌纹理、4段动画、428个关键帧。全部立方体的坐标、旋转、UV、材质及纹理内容与阶段一认可稿一致。
- 十二个链节各自保留可编辑分组，统一置于 `11_链条整体` 下。链条中段独立跟随，两端关键帧固定在挂点；锚体按刚体移动，不拉伸或缩小。
- `沉锚_动画独立备份.animation.json` 是动画编辑备份，不是可直接在 Java 原版运行的游戏资源。
- 整件 Display 调整入口仍为 `../阶段一_完整静态形体/沉锚_整体显示调整.bbmodel`，包含完整几何与纹理。它与动画母版用途不同，不能互相覆盖；初始握姿尚未经过游戏实测。

## 动作

| 动画名 | 时长 / 播放方式 | 表现 |
|---|---|---|
| `01_待机_双端固定链条轻摆` | 4秒循环 | 锚体静止，链条中段轻摆，首尾无跳变。 |
| `02_掷锚_起势出手` | 0.55秒，结束保持 | 后摆蓄势，再向前出手；链条滞后跟随。 |
| `03_落击_震颤与回收` | 1.05秒，单次 | 从掷锚末姿态连续衔接，落击短促震颤后回到待机。 |
| `04_被动_重锚短击` | 0.8秒，单次 | 短促重击与收势，回到原姿态。 |

掷锚与落击拆开，便于后续对齐真实事件。已有主动技能通过跨刻拉近流程完成落击；游戏接入应在成功施法后开始表现，并由真实 `pull_end` / `impact` 事件触发落击，不能为了固定动画长度擅自推迟伤害或改动拉近过程。掷出姿态保持期间的飞行显示、握姿及地面贴合仍属于下一接入阶段。

此阶段未修改原被动触发概率、伤害、击飞、200魔力费用、12秒冷却、目标距离或归属。原生动作预览用于看起势、落击和回收，不代表已经模拟完整10格游戏飞行。

## 验证记录

- MCP模型检查0问题；原901元素和3张纹理逐项比对保持一致。
- 实际姿态检查中，根组刚体误差小于3e-16，两端链节相对挂点矩阵误差小于8e-15。待机循环、掷出到落击、落击归位及短击归位的首尾误差均为0。
- 实际锚尖检查确认后摆、向前掷出和向下落击方向正确；中段链节随动，两端没有脱离挂点。
- 详细结果与动画母版指纹见 `实际姿态与衔接检查.json`。
- `MCP通用动画分析.json` 保留工具原始记录：通用分析器以头、手、脚等角色部位追踪运动，不识别此武器的锚尖，因而给出空运动结果及不可见运动提示。没有将该报告称为通过；此处以原生分组矩阵、锚尖轨迹和实际画面核验。未为消除提示添加无关人体骨骼。
- 阶段二交付时尚未部署。当前已通过阶段三将实际姿态转换为合法Java资源及数据包驱动，并完成部署；真实游戏画面和FPS仍未实测，原版不是直接播放此 `.bbmodel` 骨骼动画。
