# 流动水浪刃 · 动效审阅

本阶段的独立浪头因出现感突兀已被修订，最新候选见同级 `阶段四_连续水刃波动`。此文件夹保留作过程记录，尚未部署。

用户要求剑刃表现为会流动的水浪，不采用固定冰刃。此阶段保留已认可的厚环护手、潮核、链坠、宽剑根钢体与握柄，移除长冰片、冰白剑尖及剑根冰刃外层，改为两侧连续水体、起伏浪腹、上涌浪舌与随流小水滴。

水体轮廓、体积和浪舌位置均由关键帧改变，不使用滚动贴图；材质图片固定。三道浪舌随双侧水体从根部向尖端移动，接近末端收小消散。没有后期辉光。护手装饰和潮核不随水浪变形，整剑位置和握姿固定。

## 文件与动画

- `深海回响_流动水浪刃_分组动画.bbmodel`：原生分组及关键帧。两侧连续水体各 38 段、三道独立浪舌，可在动画界面调整各段；原有护手、核心、链坠与握柄分区保留。材质内嵌。
- `01_待机_水浪沿双刃循环上涌`：4.8 秒闭合循环。
- `02_施法_加速涌浪由根掠至尖`：2.4 秒、波形加宽并加速上涌，首尾与待机起始姿态一致。
- 两个 GIF 与实际分镜：交付母版的立方体、纹理、关键帧渲染，GIF 为每秒 20 帧。
- `显示调整示例/assets/deepseaecho/models/item/sword.json`：完整的待机首帧及整体 display，供 Java 模型显示界面调整握姿。原生通用 .bbmodel 和 Java 显示 JSON 用途不同。

## Java 候选帧

审阅样例导出待机 96 帧、施法 48 帧，每秒 20 帧。956 个固定元素只放在 `models/item/liquid/base.json` 中；每帧仅保存水体，通过 composite 组合。子模型的 parent 指向整体 sword.json 并继承 display，因此统一改握姿不会使水体错位。

样例 `items/sword.json` 为主副手显示选择与双通道帧分发：floats[0] 待机帧，floats[1] 施法帧；floats[1] >= 48 回到待机。已关闭换帧时的下落抬手动画。GUI/掉落展示使用完整待机首帧。

**尚未部署，也未改现有数据包驱动。** 该目录是审阅模型样例，不能只复制 items 文件就认为运行时接入完成：现有深海驱动为 32 帧，正式接入必须同步更改为 48 帧、归位标记 48，并增加 96 帧待机水浪的驱动。已有技能数值与判定保持。

## 检查与限制

完整可见模型最多 1,198 个立方体，原生 134 个分组、3 张内嵌贴图、2 段动画。Java 最高坐标 Y=31.4，保留 0.6 单位上界余量。非剑刃区域与原模型元素逐项一致，当前游戏握姿完整保留。循环及施法首尾关键帧精确闭合；导出检查坐标、合法旋转与 UV。全部 Java 帧由原生关键帧几何生成，没有另写一套预览动作。
