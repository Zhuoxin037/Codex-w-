# 圣骸第二阶段：整件与垂挂圣物

这套是实际 Blockbench MCP 建模工程，尚未接入游戏。已认可的头部几何与贴图保持原样。

- `圣骸_阶段二_整件分组模型.bbmodel`：42 个分组；头部、长柄、长短垂布、挂座、链环、灯架、亮芯、铭牌分别可编辑。贴图内嵌，直接打开。
- `审阅资源/assets/sacredrelic/models/item/sacred_relic_stage2.json`：包含整把几何的统一显示模型，纹理使用有效的英文资源路径；在 Blockbench 打开这个完整 JSON 即可调整整件 Display。保留相邻 assets 目录以加载贴图。
- 841 个立方体、5046 个四边面，原版模型合法坐标范围内。MCP 检查没有退化尺寸、无贴图面、UV 越界或共面闪烁问题。
- 当前是形体审阅阶段，尚未制作或绑定技能动画。Java 原版格式没有 Blockbench 骨骼动画模式；下一阶段会另给可编辑的动画工程，再将效果转换为游戏可调用方式。

整件预览、吊饰局部、加大垂布与背面预览均由实际保存的模型渲染。接入与动效在整件比例确认后继续。
