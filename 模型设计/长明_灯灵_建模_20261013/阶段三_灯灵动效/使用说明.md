# 长明 · 灯灵动效审阅工程

本阶段保留已确认的全部 385 个主体立方体及三张纹理，只补入独立的暗铜光眼和引焰、余光。工程共 399 个立方体、52 个分组，尚未部署到游戏。

按“动作幅度太小”的反馈，当前动画已加大：待机上下起伏约为小幅版的 1.9 倍，右手前伸约 1.9 倍、抬手高度约 2.8 倍，并增加身体前倾、衣摆跟随和引焰的长度。最新预览文件名带“幅度调整”；`灯灵_动效小幅版备份.bbmodel` 仅供回退。

2026-10-14 收暗修订：熄灭动画在 0.8 秒内同步压暗衣袍、铜饰和光眼，低魔力状态保持暗淡，复燃时逆向恢复。主体材质、轮廓和增大的动作保留；正常状态纹理帧与此前一致。最新动图为 `灯灵_熄灭收暗与复燃.gif` 和 `灯灵_完整动效预览_收暗修订.gif`。

这个工程使用内嵌的 9 个材质状态帧。查看动画时，在 Blockbench 设置的动画栏目关闭“动画中播放翻页纹理”（flipbook textures in animation），让所选动画控制材质帧。当前 MCP 会话已关闭该选项，但未改写持久设置；切到其它工程可重新打开。否则自动翻页会覆盖熄灭动画指定的收暗帧。

## 打开和编辑

用 Blockbench 直接打开 `灯灵_分组可编辑动画.bbmodel`，切到右上角“动画”，在左侧选中动画后播放。使用通用模型格式，动画、关键帧和纹理均包含在工程里，不需要 GeckoLib 或额外动画插件。

- `01_待机_托灯轻浮`：4 秒循环。整体轻浮，衣摆略滞后，灯火柔动，偶尔眨眼。
- `02_攻击_抬手引焰`：1.1 秒。右手起势、朝前引出两缕暖金焰与少量星屑，然后回到托灯姿势。左手始终托住灯盏。
- `03_熄灭_灯火渐息`：0.8 秒，并保持末帧。灯火和余烬熄灭，光眼收暗，实体本体保持原尺寸。
- `04_复燃_重新点亮`：0.8 秒。铜目重新明亮，余烬引燃火焰，回到待机初始姿势。
- `05_熄灭_安静轻浮`：4 秒循环。用于持续处于低魔力状态，灯灵保留在场。

头部、衣摆、双臂、灯盏、外焰、亮芯、尖梢、光眼及引焰分开建组。骨架关键组保留中文名并附英语后缀，便于 MCP 识别左右臂和关节。编辑模式中可见施法特效的静态原型；播放待机动画时这些特效会隐藏。

## 调整整体显示位置

`灯灵_整体显示调整.json` 是完整 385 立方体静态整体模型，不含临时攻击特效和暗铜眼的重复状态。它与同目录三张 PNG 一起，可以用 Blockbench 打开并调整 display。不要用这个 JSON 查看动画；动画在 `.bbmodel` 中。

动画动图从实际 Blockbench MCP 在 20 FPS 下求出的分组矩阵、实际几何与 UV 渲染，没有附加光晕滤镜。`动效验收.json` 记录循环、状态衔接、灯盏随手和形体保持检查。原版 Java 的模型 JSON 不承载骨骼动画；游戏接入阶段还需要将这些动作转换成资源包模型和数据包控制，不能只复制 bbmodel。

## 下一步接入约束

保留长明原有伤害和目标选择：魔力不足 200 时只停止攻击；灯灵不消失，魔力恢复后复燃。攻击动画应由实际选中目标触发。视觉实体须有明确玩家归属，跟随与清理也要覆盖切维度、下线和不再持有长明的情况。
