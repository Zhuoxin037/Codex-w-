# 长明 · 灯灵游戏接入

适用 Java 1.21.5，完整版资源包与 sweetdream 数据包配套。原有长明也会召唤，不需要重新获取。

首版位置在玩家右侧 1.05 格、后方 0.35 格、高 1.35 格，灯灵约 0.75 格高。它沿水平朝向跟随，抬头低头不会把它带到天空或地下；攻击时会朝向实际目标。

2026-10-14 朝向修正：取消跟随与攻击转向中多余的 180° 翻转，解决背对怪物的问题。此次仅更改数据包，游戏中 `/reload` 即可；现有灯灵会自动更新朝向。

- 副手持有长明：每位玩家最多一只灯灵，常驻轻浮。
- 每两秒攻击仍以玩家为中心，范围 6 格、当前魔力 ×0.02 真实伤害；没有目标时不空放攻击动画。
- 当前魔力低于 200：灯火、光眼和衣袍逐步收暗，停止攻击，实体保留。
- 魔力恢复：先复燃，再恢复托灯待机。
- 卸下、死亡、下线或跨维度：清理这位主人的旧灯；新维度重新生成，支持原版三维度。

重载方法：`/reload`，然后 `F3+T`。可用 `/function sweetdream:equipment/tool/everlit/give` 获取长明并放副手。若没有立即出现，等待下一秒的副手识别。

资源包总体 JSON：`sweetdream_rp_完整版/assets/everlit/models/entity/wisp.json`。它保留完整静态形体，供 Blockbench 打开查看；137 个游戏姿势由同目录的 geometry 与 poses 部件组成，原版不直接播放 bbmodel 骨骼动画。

后续微调悬浮位置修改 `sweetdream/data/sweetdream/function/equipment/tool/everlit/visual/follow.mcfunction` 与 `follow_attack.mcfunction` 的相同 `positioned ^-1.05 ^1.35 ^-0.35`，然后部署数据包、`/reload`。模型大小在 `visual/ensure.mcfunction` 的 scale；已存在的显示实体需卸下再放回副手刷新。

运行时一只灯只增加一个 item_display，内部 rigid 部件合在一只显示实体中；最多 381 个实际可见立方体，剔除了 281 个完全内藏的面。原始可编辑工程仍为 399 立方体。仅微小火尖的伸缩剪切用刚体近似，最大偏差约 1 毫米，其余动作保持实际 MCP 姿态。

构建源：`.workbuddy/bind_everlit_wisp.py`、`bind_everlit_wisp_dp.py`，专项检查 `test_everlit_wisp.py`、`verify_everlit_wisp_resources.py`。不要重建不存在的老资源包覆盖层；本次在现有完整版上生成灯灵独立资源。
