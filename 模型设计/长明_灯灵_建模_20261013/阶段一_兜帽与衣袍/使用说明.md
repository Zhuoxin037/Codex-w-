# 长明灯灵 · 阶段一主体

当前仅完成兜帽、光眼、领口与衣袍。双臂、灯盏、灵火及动画将在主体确认后继续，尚未接入游戏。

`灯灵_阶段一_实际模型预览.png` 是实际 MCP 保存的网格和材质渲染，不是生成的概念图。248 个立方体、24 个分组、两张内嵌纹理；正面、背面与侧面都有建模和材质。所有元素旋转为零，以阶梯体积造型。模型检查已清除共面重叠、缺贴图、零UV和无分组元素。

编辑分组和后续动画使用 `灯灵_阶段一_主体分组模型.bbmodel`，格式为「通用模型」，支持动画模式。当前阶段没有动画片段，所以动画列表为空。光眼、头部与兜帽、领口、主身及前后侧下摆均能独立选择，衣袍末段另有活动分组。

整体显示调整使用 `灯灵_整体显示调整.json`；它是整件 Java 模型，不是按部位拆散的显示文件。与同目录 `wisp_body.png` 和 `wisp_glow.png` 一起保留，便于 Blockbench 找到纹理。`审阅资源/assets/everlit/` 提供使用合法 ASCII 资源路径的模型及材质，材质位于 `textures/item/wisp/`，以后部署时会按此入口完整导出。

第一轮备份 `灯灵_阶段一_初稿备份.bbmodel` 仅用于回退，日常请打开「主体分组模型」。模型脚本都有当前工程和元素数量检查，不可在已修改的工程上直接重跑重建。

正面兜帽轮廓与确认稿做了单独比较，最终轮廓 IoU 为约84%；这是头部范围的测量，不能当作整件角色的还原率。双臂与灯盏尚未制作，整体比例还需用户审阅。整图背景、深色面腔和摄影视角会影响自动比较，已排除错误的背视和裁切结果。
