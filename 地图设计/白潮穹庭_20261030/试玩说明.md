2026-10-30 · Minecraft Java 1.21.5 · 巨构版梦核大厅，外观待试玩确认。

这是一份完整、独立的 Minecraft 游戏存档：含 `level.dat`、已建好的主世界区块、以及一个只做入场 / 出生点 / 跌落返回 / 天气时间的小功能包。**不需要** sweetdream、manacore、资源包或模组。与原数据包完全隔离，没有任何维度入口、trigger 或武器系统。

设计方案（体量、分区、材质、光影、动线）见根目录 **《白潮穹庭_设计方案_2026-10-30.md》**。

## 直接试玩

已安装到当前使用的版本：

`D:\PCL 正式版 2.10.0\.minecraft\versions\1.21.5-Fabric 0.16.10\saves\白潮穹庭_20261030`

启动 1.21.5，进入「单人游戏」选 **白潮穹庭**。列表没刷新就退回标题页再进。

- 出生在引桥桥头 `(0.5, 65, 168.5)`，面向大厅（朝北）。
- 默认**创造模式**，方便飞行看整体；想按设计动线走一遍就切生存，但**不要**从边缘掉下去——虽然会自动送回桥头。
- 跌出平台（y < 40）自动回到桥头，不会掉进虚空。
- 存档固定正午、晴天、关闭生物生成与随机刻，所以永远停在同一个下午。

复制给别人时：解压 `白潮穹庭_独立游戏存档.zip`，把里面的 **白潮穹庭** 文件夹放进对方实例的 `saves`；该文件夹下应**直接**看到 `level.dat`，不能多套一层同名目录。

## 本版建筑

白石巨构浮在云海之上。总围合 **295 × 165 × 300** 格，**434,242** 个方块，35 种方块状态，18 个结构分块。

- 主体是半径 88 的 **16 边形鼓座**（face 宽 34，斜角 11°，远看圆、近看直墙）；
- 上面是横向 86、竖向 56 的**半椭球穹顶**，落在 y=150，顶点 206，天窗半径 16；
- 大厅地面 y=64，中央 29 半径的水庭下沉到 58，水面 62；
- 两层回廊：**L1 y=112**（环宽 28，24 根柱）、**L2 y=150**（环宽 26，16 根柱）；
- 观景盘 y=166（半径 30）+ 悬月盘 y=192（半径 24），靠 16 条铜链吊在穹顶下；
- 西翼书库 / 东翼静室各 26×54，铜坡顶脊高 95；
- 引桥 18 宽、从 z=170 伸到 125，桥墩从 y=46 起、**不着地**。

主厅净高 **142 格**。这个数字是整栋建筑的立意：门廊被压到 98（唯一低于预期的地方），穹顶被拉到 206，走进去的落差就是全部。

## 动线

桥头 → 三次递进的门（引桥 / 三拱门廊 / 屏墙）→ 入厅（142 格高的空 + 脚下的水庭）→ 环廊（24 柱把空间切份）→ 西坡道 360° 上行（65→111）→ L1 → 东坡道（113→149）→ L2 → 30 级无栏悬空踏步 → 观景台 → 东侧下行回到门厅。是一条**上行闭环**，不走回头路，但会绕同一个空间两圈。
