# 甜梦回廊 · 首层试玩

Minecraft Java 1.21.5 单人独立存档。压缩包内包含 ManaCore、SweetDream、首层脚本和完整版世界资源包。手动导入时，将压缩包里的 `甜梦回廊_首层试玩` 文件夹放进 1.21.5 的 `saves`，从单人游戏打开。

## 开始试玩

- 等待大厅的**紫晶台**通往甜梦演示室。右键讲台阅读本段书页，按「下一个」切换演示，七段后循环。讲台书在地图的正常冒险模式下可阅读，书留在讲台上。
- 大厅的**铜台**打开选职业菜单。选「我」、魔导士、狂徒、歌者或同生后，会看到进场标题、布置房间和绘制地图的提示，然后进入首层。
- **按 9** 查看原版地图。副手留空时双手展开。红骷髅是层主，特殊房图标在连廊直连的邻房预览。
- 在房间中部用聊天选项开战或使用服务。用 `/trigger sd.floor_cmd set 23` 可重新打开当前选项和状态。用 `/trigger sd.floor_cmd set 3` 返回大厅。
- 回大厅时收回本局的剑、斧、弩和法杖，覆盖背包、副手、寄存箱和地图暂存栏。每次新开局重置背包和寄存箱。多余武器可寄存，开战时携带至多三把。

## 首层循环

每局随机排出 16 间房，包含普通战斗、精英、安全角落、行商、事件、铸造、占星、赌博、租借、黑市和层主等房型。首层有 8 次探索。首次进入普通、精英或其他功能房扣一次，入口、层主房和走过的房间免费。探索耗尽后可以重走旧房，并可从状态菜单「前往层主」。坠梦骑士房在地图上标红骷髅，走到即可挑战。

探索用完后，未探索房间的门洞会出现品红色玻璃屏障。开战时本房出入口暂时关闭，战斗结束后打开。

战斗和部分服务随机显示三个有效标签。选一个标签后，从匹配且职业可用的原装备里抽取一件。首层登记了 233 条真实发放入口。盔甲、法杖、剑、斧、弩和工具都沿用原包的装备与技能。梦屑用于购买补给、装备抽取、升级石和定向超限石。铸造与黑市发出的是真正的原包装备材料。

奖励标签和房间操作一项一行。随机事件使用房间生成时的变体，可能遇到旅人的遗物、回声井或停摆的钟。每间事件只结算一次，选项会写清即时结果。

### 战斗装备怎么抽

每赢一场普通战或精英战，获得一次抽取。普通房的加注沿用普通战概率。获得抽取时，先按下表抽品质，再从该档且当前职业有货的标签里随机显示三个。选定标签后，从本档相符的武器和盔甲中等概率抽一件。

| 品质 | 普通战及加注 | 精英战 |
| --- | ---: | ---: |
| 常器（T1） | 47.02% | 30% |
| 异器（T2） | 27.49% | 30% |
| 精器（T3） | 21.58% | 32% |
| 秘器（T4） | 3.91% | 8% |

普通战概率源自《以撒的结合：忏悔》1.7.9b 宝箱房 Q1～Q4 的初始参考，在参考比例上将异器的 10 个百分点移给常器。精英战抽到精器或秘器的合计概率为 40%。[宝箱房道具池](https://raw.githubusercontent.com/2o181o28/eden-seed-finder/master/item_data/itempools_rep.xml) · [道具品质](https://raw.githubusercontent.com/2o181o28/eden-seed-finder/master/item_data/items_metadata_rep.xml)

### 其他抽取来源

| 来源 | 品质上限 |
| --- | --- |
| 行商 | 秘器（T4） |
| 租借商人 | 异器（T2） |
| 赌博成功 | 禁器（T5） |

这些来源按品质上限过滤，再按职业与所选标签筛池。同池每件等概率。工具在抽取时用 T1 入池，物品沿用原稀有度显示。赌博有 60% 概率开启一次抽取。

实战中消耗通用状态会返魔；同一场消耗三种不同状态，追加返魔和治疗。开局用「我」可以直接试潮痕挂渊海、退汐消耗渊海。其他职业可用各自的起装和机制。

本层选用了现有坠梦骑士。试玩存档内的生命上限为 200，二阶段在 100 生命触发，沿用包内的招式和伤害。胜利后可在职业觉醒、刷新魔力冷却、补给之间选一项神格。

## 验证范围

使用 Minecraft 原版 1.21.5 隔离服检验进场、原版地图、教程技能、房间奖励、状态消耗、三武器限制、坠梦骑士二阶段、神格、退场和重开。隔离服用定点传送与控制台结算推进部分测试。实际客户端画面、操作手感和全装备平衡仍待试玩。部分上游超限只有发放、敲入和文案，技能机制进度按当前原包执行。

地图脚本位于 `floor_pack`，打包时复制两套数据包的当前版本并在本存档接入。源码工程与已有游戏存档不需要参与开局。
