## 进游戏先看这五处

| 位置 | 坐标（大致） | 看什么 |
|---|---|---|
| 主厅地面中央 | `0 65 -60` 附近 | 地面是不是从"灰"回到"白"；脚下 y=65、66 这两层是不是空的（能放东西了） |
| 主厅墙面 | 站在地面往四下看 | 墙是不是有竖向的明暗，而不是一片均匀灰 |
| 主厅拱顶 | 抬头 | 拱顶能不能看清肋架；会不会太暗或晃眼 |
| 后庭 | `0 65 -200` 附近 | 原来 9.4% 的死黑面是不是没了 |
| 侧廊 / 楼梯下 | `-70 65 -60`、`60 65 -120` | 这里应该比主厅暗一档——这是故意的，别当成漏光 |

## 想自己验的话

```
# 看某格的方块光/天光（调试屏 F3 右侧也有）
execute if block 0 65 -60 minecraft:light[level=15] run say 地面光在位
execute if block -32 32 -136 minecraft:light[level=13] run say 墙面光在位
execute if block -39 162 -96 minecraft:light[level=12] run say 拱顶光在位
```

`minecraft:light` 是隐形方块：站在正下方会觉得"那里有东西但看不见"，这是正常的，不是 bug。

## 已知问题（还没做）

1. **主厅厅心空中仍是暗的**。128 宽、138 高，贴墙贴地的光最多照 15 格，物理上到不了厅心。要补只能从拱顶垂铁链挂灯笼——那是加造型，等你点头。
2. **拱顶和尽端还不够暗**。现在是"全区平均提亮"，真实哥特是窗亮、拱顶暗。要更戏剧化，我可以把拱顶降一档、侧廊尽端降两档。
3. **没在客户端跑过**。帧数、Photon 光影下的表现都要你实测；存档本身是原版 1.21.5 数据，理论兼容。
