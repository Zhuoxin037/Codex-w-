# 坠梦 - FALLEN DREAM

Minecraft Java 1.21.5 地图，支持单人和多人组队，包含等待大厅和第一层「密林」。存档自带 Fallendream、ManaCore 和配套资源包。

## 进入密林

1. 到篝火旁右键「开始游戏」，或在铜砖上潜行。准备后可点击「开始游戏」或「取消准备」。已准备的玩家会开始游戏。
2. 在「坠梦研习」下方的紫晶台上潜行，进入独立研习维度。
3. 在演示室右键讲台阅读，按「下一个」切换七段实景演示。
4. 入梦过场结束后传送到独立的密林维度。按 **9** 查看地图。红骷髅标出层主朽冠鹿所在的遗迹。

沿篝火旁的右侧小径到木棚，在铜砖上潜行进入训练场。装备架分通用装备、职业装备和副手。悬停装备名看详情，点击领取。超限台用法是副手放装备，在台上潜行。离场走向「返回大厅」。

林间小径每层重新连通 16 个常规房间。过道直通，沿途有梁下照明。开局已有林地、树根和照明，首次进入才布置该房间的专属设施。只有铸造坊、行商、黑市和租借处安排营业村民。手持第 9 格的楼层地图可看到全部房间轮廓和连线，接近后显示对应图标，问号代表随机事件。新版场景随新一局生成。

每人每层有 8 次探索，首次进一间房扣 1 次。队友还没付过这间房时，代付要同时付自己和队友的 2 次；已付过这间房的队友只需再付 1 次。队伍凑不齐费用时，本次进房取消，所有人的次数都保留。旧房可重走，层主房免费。观测镜显示自己的剩余探索和队伍梦屑。个人次数归零后，可在状态菜单前往层主。

进入未清理的战斗房后，原木会分格落下。房内任何位置都可开战。打赢后需完成装备抽取、寄存或销毁，原木才会沉入地面。普通、加注和精英胜利分别给 1、2、3 梦屑，每场胜利额外抽一次装备。先选武器或盔甲，再选标签，精英的精器和秘器出率更高。饥饿条保持满格，原版自然回血关闭。

行商的三件现货摆在展台上，右键商品购买。和行商交谈可抽取装备或回收主手。每层可花 5 梦屑抽取一次，品质至少异器。战后抽到的常器、异器、精器、秘器、禁器回收价为 1／1／2／3／4 梦屑。现货按实付价格折算后再加 1 梦屑。

普通战按 5–7 点编队，加注按 8–10 点，精英按 10–12 点，精英必带 5 点的断冠猎手。每多一名参战玩家，密林普通敌怪的生命增加 35%（最多按四人档计算）。普通近战由原版护甲减伤。树脂、树根落击和断冠横扫的护甲减伤最高为 58%，单次伤害分别以玩家生命上限的 25%、25% 和 30% 为限。树脂人死亡后 0.6 秒发射十字树脂，树根每 3 秒锁定一次，预警 1 秒后落击。「苔藓」首次召唤等待 3 秒，后续冷却 5 秒。每次有效受伤让下次召唤提前 2 秒。

同一局里，每种随机事件只会出现一次。事件池抽完后，后续事件位改为普通战。未处理的事件会在房里的人全部离开后失效，草丛埋伏也可直接放弃。回声井的术纹奖励为战斗期间每 3 秒恢复 1 点魔力。十字架可以祝福，也可以献祭流火或夜火装备。首层赌博房、黑市和安全角落分别为 20%、33.33% 和 10% 的出现概率。

在装备抽取界面可寄存或销毁本次机会。队伍最多寄存两次，在安全角落选「锻造」取出。已经确定的装备类别、稀有度和标签会保留。

非战斗时，打开「状态 / 房间操作」里的「装备寄存」。手持装备点「寄存主手」直接存入。腾空主手后，点击已存的装备名取出。局内丢下的装备也会存入寄存柜。柜满时会把装备送回原主脚下。

占星室每名玩家每层可解读一次星象，获得一项本局天赋。首次抽取的人格、凡格、神格权重为 70%、25%、5%，后续排除自己已有的天赋。可在局内状态中查看「本局天赋」。

黑市的五件现货摆在展台上，分别为一件副手道具、两种升级石与两件精器及以上的装备。右键商品用生命上限结账，潜行右键用魔力上限结账。装备抽取和主手装备的专用超限石各售一次。

铸造坊以 2 梦屑抽取匹配主手装备的 α 升级石，或以 5 梦屑提升主手已装的一项升级，两项各用一次。赌房的老虎机每次花费 1 梦屑，三格相同才发奖，另有一次 2 梦屑的高阶抽取押注。租借武器在下一场战斗结束时焚毁。

每层有 25% 概率刷出一对镜房。走到相连房间后才会在地图上看见镜房图标。右键镜面进入，镜间传送免费，从出口首次踏入未探索房仍消耗一次探索。密林在两间本来可绕路到达的相邻房间之间选择一处树丛捷径。拿主手武器右键并确认交出，达到队伍所需数量后，小径才会铺出来并画上地图。

击败朽冠鹿后，每位存活队员从三项未拥有的神格中选一项。若可选项少于三项，则展示余下的选项。队伍领取完毕即可进入独立的跨层试验维度。转层保留梦屑、本局装备与天赋，重新获得 8 次探索。若带超过 10 梦屑，赌博房顶替一个事件房。若首层没刷黑市且略过已到访的占星室，下一层黑市概率升至 2/3。若换层时生命低于 20%，安全角落的概率升至 60%。测试层沿用密林的房间模板。

- `/trigger sd.floor_cmd set 23` 打开状态和当前房间操作。
- `/trigger sd.floor_cmd set 3` 返回大厅。

手动安装时，把压缩包里的世界文件夹放进 Java 1.21.5 的 `saves`，再从单人游戏进入「坠梦 - FALLEN DREAM」。
