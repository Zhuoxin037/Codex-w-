# 梦核哥特 · 门庭与彩光主厅

用户认为门庭“还可以”，指出部分柱子和彩窗被裁断，并要求修改后继续制作。本轮从已游玩的当前门庭存档复制工作副本，局部修复构件，向后续建主厅；没有重跑阶段七生成器覆盖原世界。

旧的「梦核哥特_玫瑰门庭样段_20261030」保留，修改和扩建出现在这个新版本中。当前玩家的位置、背包、进度和统计随源存档保留；新玩家仍从入口水庭进入。交付时确认源存档自复制起未发生变化。世界为原版 Java 1.21.5，默认创造，无外部数据包、资源包或模组依赖。

这次修复了三类问题：

- 尖拱曲线在陡转弯处逐列取点，原先产生断开的拱肩。现在补齐相邻列的连接，检查了门拱、回廊、塔楼及基座等 101 组拱线。
- 入口下方三扇小彩窗与多重门拱及两根束柱发生穿插。移除冲突组合，改为门拱两侧完整的细长彩窗；恢复两侧主束柱，塔窗收进各自楼层的净空范围，避免楼板和屋面切过窗面。
- 原先悬空的上部镂空冠饰增加支撑。续建楼梯与连接平台绕开原塔柱，并将下层侧廊拱顶控制在上层地板以下。

新增主厅位于门庭后方，向北延伸约 130 格。沿中轴进入，可以看到高处的八扇侧窗、端部三联长窗、连续横向肋拱、长水池与中间横桥。水池两侧可步行到尽端。左右门庭二层回廊后方，通过绕塔平台和十四级楼梯，可进入主厅上层露台；上层外侧有栏杆与扶壁。

需要直接查看时，可以在创造模式飞行，或使用以下传送点：

```
/tp @s 24.5 57 100.5 180 0
/tp @s 13 65 -45 180 0
/tp @s 48 112 -85 180 0
```

第一行为门庭入口，第二行为主厅入口侧，第三行为主厅上层。首次入场与跌落返回机制延续原存档。高塔内部的完整上下交通、侧翼、后方庭院以及整座城堡的生活空间仍未完成；这是门庭修复与主厅扩建版本。
