## 新增区域与路线

西翼书廊从主厅西侧第一段侧廊向外走入，入口约在 (-78,65,-81)。书廊包含两层阅读空间、中央挑空、嵌墙尖拱书架、阅读桌椅、顶梁与吊灯。西侧两跑楼梯共 47 级，从 Y65 上到 Y112；上层通过短桥接回主厅上层。后方还连接一座低于入口双塔的开敞书塔，两层均有平台通行。

东翼花厅从主厅东侧约 (82,65,-115) 进入。这是一个通高房间，四周保留完整的大彩窗，上方是带白色石肋的玻璃屋顶；内部设浅水池、植物台和休息座位。室内装饰避开了主要行走路线和窗面。花厅目前只有地面一层。

后庭从主厅尽端两侧绕出，不穿过尽端三联彩窗。地面通路在 x±48 附近接入庭院；主厅 Y112 上层也通过横向平台接入两侧回廊。庭院设四片静水、十字步道、双层尖拱回廊与北端月窗亭。月窗亭的圆形彩窗独立于楼板和屋面，双层回廊在北端横向连通。

如果想直接查看，可在创造模式使用：

```

/tp @s -118 112 -90 180 0
/tp @s 112 65 -115 180 0
/tp @s 0 65 -180 180 0
/tp @s 93 112 -212 180 0
```

依次为书廊地面、书廊上层、花厅、后庭入口及后庭上层。正常步行也能进入上述区域。
