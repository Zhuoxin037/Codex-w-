# 梦核哥特 · 玫瑰门庭样段

阶段六构图概念获用户“可以的”认可后，制作了这个实际方块样段：先落地入口主立面、玫瑰彩窗、高低双塔、双层尖拱敞廊与水庭。它是整座城堡的首个建筑样段，尚不是完整城堡；本次实际建筑外观等待试玩反馈。

在 Minecraft Java 1.21.5 的单人游戏列表中打开 **梦核哥特_玫瑰门庭样段_20261030**。已安装至：

`D:\PCL 正式版 2.10.0\.minecraft\versions\1.21.5-Fabric 0.16.10\saves\梦核哥特_玫瑰门庭样段_20261030`

同目录的 `梦核哥特_玫瑰门庭样段_20261030_独立存档.zip` 可供备份或另行安装。解压后，把包含 level.dat 的整层世界文件夹放入 saves。不要覆盖已经游玩或修改过的同名世界。

本样段独立运行，无 sweetdream、manacore、资源包或模组依赖。默认创造、固定正午；首次进入位于水庭右侧入口（24.5, 57, 100.5），面向主立面。进入世界不会重新生成建筑，手工改动可正常保存。此前大厅、入口柱廊样段以及其他聊天的白潮穹庭均未覆盖。

从水庭走上中央楼梯进入一层门庭。左右回廊后侧有通往二层的楼梯。可用创造飞行查看高塔、窗饰厚度和塔楼开口；高塔内部交通、后方主体、完整屋面与内部装饰尚未完成。水庭外围是样段边界，跌落到下方会返回入口。

建筑占地约 225×171 格，高度范围 Y33—257，共 246,780 个方块。重点制作了多重尖拱入口、十二分区玫瑰窗、环形花瓣窗棂、细长彩色柳叶窗、束柱、开敞钟楼和两层回廊。概念中的完整后方塔群、深远庭院、桥廊网络与梦核光色氛围仍需后续展开；当前白天原版表现不等于概念图的最终效果。

`门庭整体.png`、`玫瑰窗与尖拱.png`、`双层敞廊.png` 来自方块布局与原版纹理的离线渲染，并已逐点核对保存存档的对应方块类型。它们不是游戏客户端截图，透明排序、原版光照、部分连接状态和光影包表现可能不同。阶段六图片仍只属于概念图。

已完成原版 1.21.5 建造检查 110 项、导出重开与新玩家验证 10 项；包括楼梯逐级净空、首次出生、空背包、跌落返回和无遗留强制加载。实际区域文件核对 246,780 个预期位置的方块类型，错误 0；这不等于逐项验证全部方块属性，也不代替外观审阅。独立存档 ZIP CRC 通过，安装的 56 个文件与导出源哈希一致。未进行客户端行走录像、截图或 FPS 测试。

后续修订应以试玩后的当前独立存档为来源，先保留用户修改，再做局部调整。生成和导出入口已设置安装后保护，不能重跑生成器覆盖试玩世界。


后续状态：用户初步认可门庭并指出柱窗裁断，已在阶段八完成本轮定位问题的修复并续建主厅。新的独立世界为「梦核哥特_门庭与彩光主厅_20261030」，本阶段旧世界保留；见相邻阶段八目录的《扩建版试玩说明.md》。
