## 地图入口

入口在既有碎石路面上，脚底位置 **(61.5, −34, 550.5)**，yaw180，面向上山方向。

独立地图现有的首次进入、世界出生、个人重生和跌落返回都指向这里。已进入过旧前庭的玩家，下次进入时会迁移到道路入口一次；之后正常走路不会反复拉回。旁观模式不启用跌落返回。

原坐标接入地图时，可使用：

```mcfunction
execute in minecraft:overworld run tp @s 61.5 -34 550.5 180 0
```

也可执行 `function dreamcourt:arrive`，同时设置玩家重生点。命令方块选择最近玩家时使用 `execute as @p run function dreamcourt:arrive`。本轮只修改本独立地图的dreamcourt包，没有接入或改动sweetdream/manacore。
