# 梦核哥特城堡 · 巨构试玩

用户最新修订：**偏梦核的欧式哥特城堡，并且要有彩窗**。本轮依据这个方向制作。普通圆塔要塞版及此前交通候厅式扩建保留为过程稿，不作为本轮认可外观。

## 进入世界

Minecraft Java 1.21.5 单人游戏选择 **梦核哥特城堡_巨构试玩_20261030**。默认创造，首次出生在城门外 `(0.5, 65, 88.5)`，面朝城门。

这是独立游戏存档。仅内置出生和跌落返回功能，不需要 sweetdream、manacore、资源包或模组。进入不会重新生成建筑，手工修改正常保存。跨电脑使用同名 ZIP，解压后把包含 `level.dat` 的完整文件夹放进实例 `saves`。

## 这一版的建筑语言

- 瘦高塔身、针状尖顶、成组小尖塔、陡屋顶与石质山墙建立上扬轮廓。
- 主堡高侧窗、玫瑰窗、窄长尖拱窗、窗棂与尖山花形成哥特立面。
- 飞扶壁跨过下层侧翼，连接外侧支墩和主堡高墙；大殿内有横向肋拱、对角肋及连续拱顶脊线。
- 梦核通过冷白石材、淡色彩玻璃、静水、少人尺度参照与空旷空间呈现。门楼、内庭、双翼、高台与围墙仍组成城堡。

用地 **320×384格**，最低地基 `Y=58`，最高尖顶 `Y=249`，主地面玩家站立高度 `Y=65`。约135万保存方块；最高塔尖比主地面高184格。

## 彩窗

5,338个玻璃方块按图案设计，不是随机配色：

- 前后两面大型玫瑰窗：八向花瓣、放射窗棂、浅色中心及少量琥珀色外环。
- 玫瑰窗两侧的高长窗：成串菱形花瓣和纵向主线。
- 主堡高侧成对长窗：重复的雾蓝、紫、粉色花瓣纹样。
- 门楼窄窗：蓝紫与粉色中心，顶部少量暖色玻璃。

由原版染色玻璃和石质窗棂组成，不依赖贴图替代实际几何。本轮没有附带彩色投影光影；原版玻璃颜色与光影模组的彩色投影是不同效果。

## 建议路线

从双塔门楼进入前庭，穿过原先认可的入口柱廊和水庭，再进入主堡大殿。可以先在内庭仰望主堡的玫瑰窗，再沿东翼楼梯上行，从高廊看成对彩窗和肋拱。东侧阅读翼、西侧水室、北部高台保留相通路线。

前庭东侧约 `(122,65,52)` 的宽楼梯通往 `Y=90` 城墙步道，可沿角塔、侧塔和门楼走完整圈。门楼上层石桥跨越地面城门。高塔与尖顶的高层以外观为主，没有为所有塔的每一层设置内部楼梯，可用创造飞行查看。
