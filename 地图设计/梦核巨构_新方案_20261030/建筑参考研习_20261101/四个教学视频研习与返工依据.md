# 四个教学视频研习与返工依据

2026-11-01。用户再次否决“换塔帽后与原塔身结合”的效果，提供以下四个视频要求学习。本轮停止安装该试稿，先核对教程中的实际施工画面。

## 本轮实际查看方式

读取四个B站页面的公开信息及公开360p视频，沿全长时间线抽取画面，先查看整体进度，再加密复核轮廓、雕花、墙顶交界和浅色墙面片段。查看了视频内嵌字幕和施工画面。公开接口未返回字幕文件；本轮没有连续听读整段音频，也没有逐秒观看，不能写成“完整看完一小时视频”。关键帧时间约有两秒偏差。

原视频与中间画面仅在项目研习目录保留，不重新发布作者教程。以下只记对当前制作有帮助的方法和本项目判断。

## 1. 先把造型放到建筑尺度里判断

[《如何设计中世纪、哥特、奇幻风建筑？10个基础的设计技巧》](https://www.bilibili.com/video/BV1fDsX6LEWe/)，小满不经心中配，原作者Calven。

约00:24—03:12：先标中心与侧面轮廓，调整坡度过渡，再沿塔身平面补屋面。约11:12—16:00：窗洞的凹凸层次与半砖等小截面；约20:00—21:36：附属屋面和主塔的视觉平衡。

对本项目的判断：原样主塔长锥顶放在分塔上不成立；另换一个精细塔顶，也不能自动修好方盒钟楼与厚平台。必须把塔身上段、开口、檐口和塔帽放在同一张正侧面里判断，再放回全城堡看主次。

## 2. 哥特细节靠截面、凹槽与承接

[《五种哥特式柱体雕花》](https://www.bilibili.com/video/BV14p4y117Za/)，一只小太阳DSun。

00:41、05:48、07:16、10:21、13:51为作者标出的五段起点。实际画面展示了不同用途的柱饰：窄竖构件与深色内退面、阶梯状托座、顶端收口，以及斜盖扶壁的侧面回接。楼梯、半砖、墙和栅栏在截面中各司其职。

对本项目的判断：塔头四角的粗实心块需要重新组织为承重芯与细附柱；白檐应有檐下倒角和托座，不能在复制屋面下面再垫一张厚方盘。侧面、背部和转角也必须成立。

## 3. 柱头、连续檐线与顶面要共同设计

[《维尔茨堡宫宫廷礼拜堂内饰教程》](https://www.bilibili.com/video/BV1813g6kEzq/)，天涯共磁石。

约01:12—03:36可见柱列、窗位和楼层檐线的施工次序；约04:48—05:12、07:00可见墙顶交界向顶面的连续转折。细节聚集在柱头、檐线与重点部位，墙面、顶面和装饰具有不同分工。

对本项目的判断：学习空间比例、细部组织和连接方法。梦核哥特基调继续保留；不直接引入该巴洛克/洛可可实例的整套金饰与配色。视频简介提到冻结更新调试，具体构件能否在1.21.5稳定保存须另验，不能默认可用。

## 4. 材质变化要成片、有成因

[《MC 快速提升建筑质感：做旧》](https://www.bilibili.com/video/BV1z14y1E7V2/)，Cab4822。

约00:48—01:36：从连续斑块组织材质过渡；约02:00—03:12：沿墙面组织雨痕和浅色石材变化。纹理强弱、颜色相近程度与分布方向共同影响结果。

对本项目的判断：浅色外墙可在檐下、水边和基脚安排克制的变化，避免每个位置等概率换方块。梦核建筑仍需安静、干净的大面；不把整座城堡改成破败遗迹，也不用材质噪点掩盖造型问题。

## 现有塔头必须一起返工的内容

| 部位 | 目前的问题 | 后续施工依据 |
|---|---|---|
| 整体轮廓 | 塔帽孤立选择，放回塔身后主次与尺度失衡 | 先检查完整正侧面；短屋帽、窗段、细尖分别占多少高度需一起推敲 |
| 钟楼上段 | 大块四角和方盒开口，没有随帽檐组织细柱 | 连续束柱、内退开口、完整拱肩与柱头，共同接到檐口 |
| 檐口 | 平台与新屋帽底部重复，边缘厚重 | 将原方盘与屋帽底座作为一个截面处理，检查檐下倒角、转角和承接 |
| 细部 | 只更换塔帽，柱头、边柱及相邻墙面仍粗糙 | 先完成一座完整塔头及邻接一跨，检验侧面进退和细部尺度 |
| 颜色 | 换色无法补救比例问题 | 保留用户选择的浅灰屋面、白檐边、淡紫窗色；原版照明仍是白光 |
| 展示 | 孤立尖顶和局部取景不足以判断整体 | 同时提供完整上段正侧面、塔身连接近景、放回城堡后的尺度关系 |

本表是本项目的返工判断，不冒称为四位视频作者的原话或统一规则。尚未据此完成新的建筑，不把研习记录当作建筑成果。
