# 梦核城堡 · 巨构试玩

用户最新要求：整体更偏向城堡。本轮将巨构组织为双塔城门、环城墙、内庭、带四座高塔的主堡、左右翼和后部高台。浅色石材、淡蓝玻璃、水庭与空旷空间延续梦核方向；石板陡屋顶、尖塔、垛口、尖拱、扶壁与屋顶老虎窗建立城堡轮廓。

## 进入

Minecraft Java 1.21.5，单人游戏选择 **梦核城堡_巨构试玩_20261030**。默认创造模式，首次出生在城门外 `(0.5, 65, 88.5)`，面向城门。世界独立运行，仅内置出生与跌落返回功能，无 sweetdream、manacore、资源包或模组依赖。

其他实例使用同名 ZIP：解压后将含 `level.dat` 的完整世界文件夹放进该实例 `saves`。不要覆盖其他存档。世界进入时不会重建建筑，后续手工修改可正常保存。

## 建议路线

1. 从双塔城门穿过，沿前庭浅色步道进入原先认可的三重入口与柱廊。它现在是城堡内庭。
2. 穿过水庭后方已打开的通道进入主堡大殿。主厅保持高空间、下沉水面、两侧多层回廊与跨厅桥。
3. 东侧为阅读翼，西侧为四间水室；东翼两段带平台的上行楼梯连接二层与高廊。主堡高层保留跨厅观景路线。
4. 沿北部露台的宽楼梯前往高台和小殿，从后部回望主堡屋顶与塔楼。
5. 回到前庭，在东侧 `(122, 65, 52)` 登上宽楼梯，可到 `Y=90` 的城墙步道。城墙经过角塔、侧塔与门楼，形成整圈路线；门楼上层跨越地面城门。

塔楼已设置与地面、城墙或主堡回廊相接的门洞与楼板。高处屋顶和尖塔以建筑外观为主，本轮没有为每座塔的所有高层设置内部楼梯。可用创造飞行查看屋顶与背面。

## 体量与建造内容

整体用地约 **320×384 格**；屋檐极值外包宽 321 格。地基最低 `Y=58`，最高塔尖 `Y=215`，比主地面高约150格。实际保存约137万方块。

- 十二座圆塔：四座角塔、两座侧塔、双塔门楼、四座主堡高塔。
- 连续城墙与垛口、门楼尖拱及升起的栅门、可通行城墙步道。
- 主堡大陡屋顶、双翼坡屋顶、老虎窗、石质山墙、圆窗、尖拱窗、层叠塔檐、扶壁及收边。
- 已有入口柱廊、水庭、阅读翼、水室、跨厅桥和高台融入城堡结构。

本轮是城堡建筑试玩版，外观等待本轮审阅；家具、剧情与肉鸽机制没有因此全部完成。
